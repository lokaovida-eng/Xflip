**Xflip** is an ultra-lightweight, high-performance cover screen launcher and multitasking utility designed specifically for **Samsung Galaxy Z Flip 5, Z Flip 6, and Z Flip 7** foldable smartphones. Xflip allows users to execute full Android applications directly on the outer cover display without unfolding the phone.

---

## ✨ Key Features & Highlights

- 📲 **Full Cover Screen Execution**: Launch any installed Android application on the outer Z Flip cover display.
- 📁 **Smart App Folders & Categories**: Organize cover screen apps in custom folders for quick access.
- ⚡ **1-Tap One-Touch RAM Cleaner**: Instant memory optimization utility integrated right into the cover widget.
- 🔒 **App Privacy & Hiding**: Hide sensitive apps from the outer display with pin/biometric lock protection.
- 🎨 **Custom Color Themes & Glass UI**: Personalize accent colors and glassmorphic card overlays.
- 🌐 **Multilingual Support**: Supports English, Portuguese, Spanish, German, French, and Japanese.
- 🔋 **Battery Efficient**: Zero background daemon battery drain with lightweight Native Cover Window Management.

## 🚀 How to Install & Launch

1. Download the latest `Xflip.apk` installer from the [Releases](https://github.com/lokaovida-eng/Xflip/releases) section or clone the repository.
2. Grant "Draw over other apps" and "Accessibility Services" permissions for cover screen rendering.
3. Add the **Xflip Cover Widget** to your Galaxy Z Flip Cover Screen widgets list!
